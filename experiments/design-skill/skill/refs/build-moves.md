# Build Moves — Generative Application of the 98 Laws

For design *building*, not review. Entry point is creative intent ("I want this surface to feel X") or a blank page, not a checklist. Laws become design moves — including deliberate breaks. Every composition names its cost.

---

## Intent → Laws

Map common design intents to the laws that serve them. Load the cluster ref for each law's full statement and example.

### Calm
- **D-17 Reduction** — remove until removal harms; then remove one more.
- **D-30 Signal-to-Noise** — every non-signal element actively degrades what it surrounds.
- **D-74 Highlighting** — ≤10% highlighted; restraint is the move.
- **D-67 Entry Point** — the entry sets the tone; calm entry = calm surface.
- *Avoid:* D-90 Threat Detection, D-31 Goal Gradient (urgency cues), D-13 Contrast (high).

### Premium
- **D-15 Aesthetic-Usability** — visual quality is a trust signal; premium reads as better.
- **D-70 Proportion** — golden ratio, rule of thirds; harmony reads as craft.
- **D-67 Entry Point** — premium entries are deliberate, not accidental.
- **D-17 Reduction** — negative space reads as confidence.
- *Avoid:* D-29 Progressive Disclosure (premium surfaces don't hide), D-86 Redundancy.

### Trustworthy
- **D-26 Trust-Through-Consistency** — repetition teaches rules; violations fracture trust.
- **D-22 Familiarity** — conventions are free trust; novelty is a tax.
- **D-64 Perceived Control** — users trust what they can control and undo.
- **D-19 Feedback** — every action acknowledged; silence reads as failure.
- *Avoid:* D-71 Form Follows Function (if function is unfamiliar), D-89 Symmetry breaks.

### Urgent
- **D-90 Threat Detection** — use only when the urgency is real; cried-wolf erodes trust.
- **D-31 Goal Gradient** — visible proximity to the goal accelerates action.
- **D-20 Responsiveness** — 0.1s for cause-and-effect; lag kills urgency perception.
- **D-13 Contrast** — break calm; high contrast forces attention.
- *Avoid:* D-17 Reduction (density can read as urgent), D-29 Progressive Disclosure (hide nothing urgent).

### Playful
- **D-25 Emotional Resonance** — play is emotional first, functional second.
- **D-56 Story Form** — narrative framing turns tasks into play.
- **D-47 Social Mirroring** — visible others make it feel like a game.
- **D-58 Variable Reward** — surprise sustains play; predictability kills it.
- *Avoid:* D-38 Cognitive Friction (play tolerates some friction), D-22 Familiarity (some novelty is the point).

### Authoritative
- **D-14 Visual Hierarchy** — one clear reading order; authority is structure.
- **D-23 Principled Decision** — every choice traceable to a principle; authority is defense.
- **D-88 Serial Position** — open strong, close stronger; middles are forgettable.
- **D-71 Form Follows Function** — visible form matches function; no decoration.
- *Avoid:* D-40 Muddling Through (authority doesn't muddle), D-58 Variable Reward.

### Intimate
- **D-67 Entry Point** — small, deliberate entries; intimacy is scale.
- **D-56 Story Form** — narrative over data; intimacy is voice.
- **D-25 Emotional Resonance** — feeling over function; intimacy is register.
- **D-42 Examples Before Abstractions** — concrete is intimate; abstract is distant.
- *Avoid:* D-13 PARC high contrast, D-30 Signal-to-Noise maximization (intimacy tolerates softness).

### Learnable
- **D-42 Examples Before Abstractions** — examples first, always.
- **D-9 Recognition Over Recall** — cues not memory; the surface teaches.
- **D-32 External Memory** — state in the world, not the head.
- **D-45 Habit Loop** — cue-routine-reward; learning is habit formation.
- *Avoid:* D-55 Shortcut Threshold (learners need full paths first), D-22 Familiarity if the domain is new.

### Delightful
- **D-58 Variable Reward** — surprise is the core move.
- **D-25 Emotional Resonance** — delight is felt, not analyzed.
- **D-31 Goal Gradient** — visible progress is itself delightful.
- **D-47 Social Mirroring** — others' delight is contagious.
- *Break deliberately:* D-22 Familiarity (one surprising moment), D-89 Symmetry (asymmetric delight).

### Scalable (information-dense)
- **D-81 Modularity** — break into comprehensible units; density survives at scale.
- **D-29 Progressive Disclosure** — reveal on demand; density without overload.
- **D-8 Miller's Constraint** — chunk to four; density demands chunking.
- **D-83 Performance Load** — minimize total effort; density is not load.
- *Avoid:* D-17 Reduction (density needs content), D-67 Entry Point (can't be minimal at scale).

## Law Tensions

Pairs that pull against each other. Resolution principles are the creative move.

### D-17 Reduction vs D-86 Redundancy
- *Tension:* minimal vs robust. Remove vs repeat.
- *Resolution:* redundant only what's critical. Decorative redundancy is noise; load-bearing redundancy is safety.

### D-22 Familiarity vs D-71 Form Follows Function
- *Tension:* convention vs function-driven form.
- *Resolution:* follow convention unless function demands departure. The departure must deliver measurable value (D-24 Outcome Over Aesthetic) that outweighs the relearning cost (D-22).

### D-29 Progressive Disclosure vs D-27 Discoverability
- *Tension:* hide vs reveal. Hide details, but never hide existence.
- *Resolution:* the user must know the hidden thing exists, even if they don't see its details. A collapsed section heading is discoverable; an undocumented feature is not.

### D-8 Miller's Constraint vs D-32 External Memory
- *Tension:* hold less in mind vs offload more to the world.
- *Resolution:* both apply. External memory reduces what's in the head; Miller sets the ceiling for what remains. Use both — don't pick.

### D-38 Cognitive Friction vs D-42 Examples Before Abstractions
- *Tension:* zero friction vs examples that may slow the path.
- *Resolution:* examples reduce friction overall, even if they add steps. A 3-step example path beats a 1-step abstract path. Friction is confusion, not length.

### D-15 Aesthetic-Usability vs D-24 Outcome Over Aesthetic
- *Tension:* beauty affects perceived usability vs outcomes are what matter.
- *Resolution:* aesthetics serve outcomes (trust, adoption, tolerance). Beauty without outcome is decoration. Measure both.

### D-25 Emotional Resonance vs D-24 Outcome Over Aesthetic
- *Tension:* feeling matters vs outcomes matter.
- *Resolution:* feeling is an outcome. Emotional register is a measurable input to completion, error rate, and confidence. Don't subordinate emotion to "function."

### D-26 Consistency vs D-71 Form Follows Function
- *Tension:* repeat patterns vs let function dictate form.
- *Resolution:* consistent within a function class; vary across function classes. Don't force consistency where functions genuinely differ.

### D-13 PARC Contrast vs D-89 Symmetry
- *Tension:* contrast creates emphasis vs symmetry creates balance.
- *Resolution:* contrast within symmetry. Symmetrical layouts with one high-contrast focal point combine both. Asymmetry + contrast = chaos.

### D-19 Feedback vs D-29 Progressive Disclosure
- *Tension:* always show feedback vs hide until needed.
- *Resolution:* feedback is never the thing to hide. Hide options, not acknowledgments.

## Deliberate Breaks

When breaking a law is the design move. Every break names its cost — no free breaks.

### Break D-89 Symmetry
- *Effect:* tension, energy, modernity, directional pull.
- *Cost:* loss of balance signal; users may read as unstable or incomplete.
- *When:* brand differentiation, editorial energy, deliberate discomfort.

### Break D-13 PARC Alignment
- *Effect:* disruption, warning, intentional notice.
- *Cost:* structural signal lost; users spend cognitive effort finding the pattern.
- *When:* error states, warnings, deliberate interruption of flow.

### Break D-22 Familiarity
- *Effect:* differentiation, brand voice, novelty as feature.
- *Cost:* relearning cost; users slower on first encounter; error rate rises.
- *When:* the departure delivers measurable value; the cost is paid by the user once and recovered over time.

### Break D-17 Reduction
- *Effect:* density, richness, maximalism, expertise signal.
- *Cost:* cognitive load; scan-time rises; abandonment risk on long surfaces.
- *When:* expert audiences, dense data surfaces, maximalism as brand.

### Break D-26 Consistency
- *Effect:* emphasis on the broken instance; the exception becomes the signal.
- *Cost:* trust fracture; user relearns the rule for that one case.
- *When:* one element deserves emphasis that consistency would flatten.

### Break D-14 Visual Hierarchy
- *Effect:* equality, choice, user-directed priority.
- *Cost:* user must construct their own hierarchy; cognitive tax.
- *When:* genuinely equal options (rare); choice architecture where the user's priority is the point.

### Break D-19 Feedback
- *Effect:* suspense, anticipation, dramatic pause.
- *Cost:* user may read silence as failure; double-submits; trust erodes.
- *When:* very rare — only when suspense is the intended experience and the cost is honestly paid.

### Break D-38 Cognitive Friction
- *Effect:* forced attention, ritual, ceremony, deliberation.
- *Cost:* abandonment; every friction moment is a drop-off candidate.
- *When:* irreversible actions deserve friction (D-35 Confirmation); learning moments may earn small friction.

## Compositions

Named moves that combine laws into known effects. Each is a recipe — apply the listed laws together.

### Negative Space as Luxury
- **D-17 Reduction + D-67 Entry Point + D-73 Gutenberg + D-74 Highlighting**
- *Effect:* emptiness reads as confidence and craft. The single highlighted element becomes precious by isolation.
- *Apply to:* premium product surfaces, editorial layouts, hero sections.

### Progress as Motivation
- **D-31 Goal Gradient + D-53 Progress-Mastery-Control + D-19 Feedback + D-32 External Memory**
- *Effect:* visible progress, felt mastery, persistent state. The user sees how far they've come, knows what's next, and can resume.
- *Apply to:* onboarding, long forms, multi-step flows, learning paths.

### Conversational Warmth
- **D-56 Story Form + D-25 Emotional Resonance + D-47 Social Mirroring**
- *Effect:* the surface speaks, not displays. The user feels addressed, not processed.
- *Apply to:* empty states, error messages, onboarding copy, confirmation pages.

### Expert Density
- **D-81 Modularity + D-55 Shortcut Threshold + D-45 Habit Loop + D-8 Miller (stretched)**
- *Effect:* dense surface that rewards expertise. Power users get shortcuts; novices get full paths; chunking keeps Miller in check.
- *Apply to:* dashboards, pro tools, IDEs, trading interfaces.

### Trust Through Transparency
- **D-27 Discoverability + D-19 Feedback + D-32 External Memory + D-64 Perceived Control**
- *Effect:* nothing hidden, everything acknowledged, state in the world, control in the user's hands.
- *Apply to:* settings, privacy surfaces, financial flows, data management.

### The Deliberate Surprise
- **D-58 Variable Reward + D-25 Emotional Resonance + D-22 Familarity (one break)**
- *Effect:* a familiar surface with one unexpected moment. The break creates the memory.
- *Apply to:* milestone moments, achievements, completion states, brand expression.

### The Recovery Story
- **D-37 Undoability + D-21 Error Inevitability + D-56 Story Form + D-64 Perceived Control**
- *Effect:* errors become narrative beats, not failures. The user recovers, the system helps, trust compounds.
- *Apply to:* error states, failed actions, deleted items, expired sessions.

### The Familiar Stranger
- **D-22 Familiarity (mostly) + D-71 Form Follows Function (one break) + D-67 Entry Point**
- *Effect:* a recognizable pattern with one function-driven departure. The unfamiliar is contained and explained.
- *Apply to:* novel features inside a known product, innovative tools in a familiar category.

### The Calm Expert
- **D-17 Reduction + D-83 Performance Load (minimized) + D-81 Modularity + D-55 Shortcut Threshold**
- *Effect:* minimalist surface that hides depth. Calm at first glance; powerful for those who look further.
- *Apply to:* pro tools that don't intimidate newcomers, writing apps, note-taking tools.

### The Honest Warning
- **D-90 Threat Detection + D-30 Signal-to-Noise + D-35 Confirmation + D-37 Undoability**
- *Effect:* the warning is loud, the surface is quiet around it, the action is gated, the recovery is available.
- *Apply to:* destructive actions, irreversible changes, data deletion, privacy impacts.

## Generative Prompts

Questions that drive creative application. Use when the model is starting from intent, not from a checklist.

- What does this surface need more of? What does it need less of?
- Where can I break a law to create meaning? Which break is honest, which is lazy?
- Which law is doing the most work here? Which is doing none?
- If I had to remove one element, which removal would make the others stronger?
- What is the user's emotional state when they arrive? Which laws serve that state?
- What would happen if I inverted the primary cluster here? (Calm → urgent; premium → intimate; authoritative → playful.)
- Where am I spending the user's attention? Is each spend earning its place?
- What is the one thing this surface must do? Which laws protect that? Which laws fight it?
- If this surface were a room, what would it feel like to walk into? Which laws produce that?
- What does the user need to remember when they leave? Which laws make that stick?
- Which composition from this file is the closest match to the intent? What would I change about it?
- Which law tension is most alive on this surface? What is the resolution principle?
- Which deliberate break would serve the intent? What is the cost I'm willing to pay?
- What would the most restrained version of this surface look like? What would the most generous version look like? Where on that spectrum does the intent live?
- If I could only keep three laws from the 98, which three would do the most work for this surface?

## How to use this file

1. Start from intent — pick the closest match in §1.
2. Load the cluster refs for the named laws to get their full statements and examples.
3. Check §2 for the law tensions most active in your design; resolve them explicitly.
4. Consider §3 — is a deliberate break part of the intent? Name the cost.
5. Pick or adapt a composition from §4 — combinations produce emergent effects single laws don't.
6. Run §5 prompts against the draft; the answers reveal what's missing or overdone.
