
Build a release-candidate review harness. Inventory every user-facing surface against its documented acceptance criteria: features, states, workflows, and risk-ranked edge cases. Verify each as a real user would, capturing concrete evidence (steps, expected vs. actual, severity, logs, traces) for every defect, regression, and spec deviation. Triage findings by shared root cause and blast radius; resolve blockers first, then coherent fix batches, each gated by regression tests. Maintain a living release scorecard: pass/fail per acceptance criterion, open defect counts by severity, rollout-blocking issues, and residual risk with explicit owner and justification. Re-run the full verification inventory after each fix batch until: all P0/P1 criteria pass, no unowned rollout-blockers remain, and residual risk is signed off or explicitly deferred. Stop the release and escalate immediately on any blocker that cannot be cleared within the candidate window. Ask before touching production, real customer data, paid infrastructure, or any destructive or irreversible action; default to read-only verification.
