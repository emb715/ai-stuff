# /vault-start

OpenCode command. Routes the current session to the correct framebook procedure.

## When to use

At the start of any OpenCode session in this vault.

## What it does

Asks for session type, scans for prior work, routes to the matching framebook procedure.

## Invocation

```
/vault-start
```

## Related

- `init/` — paste-in version for non-OpenCode tools
- `_meta/framebook/start-session/` — the underlying procedure
