# Wins

- `strip-attribution` removes Claude attribution from PR, issue and comment bodies through a `PreToolUse` hook, verified locally (plugin) and in a claude.ai/code cloud environment (setup script).
- `ndv-pr-review` posted its first end-to-end review from a GitHub Action and caught a planted rate-limiter bug as two verified Warnings.

# What failed

- The first version, a project-level `gh` hook in another repo, missed the main path: cloud sessions create PRs through GitHub MCP tools, not `gh`.
- `ndv-pr-review` in a headless Action: a background agent ended the run before its result arrived (no comment posted), and Sonnet skipped Flow, the base-vs-head tests and explain while they were optional. Both fixed in 0.9.0.

# What changed in process

- `.claude-plugin/marketplace.json` at the repo root makes the vault a Claude Code plugin marketplace.
- `ndv-pr-review` Action auth moved to a Claude Code OAuth token, because workload identity bills API credit, and promotional credit does not cover Claude Code.
- `strip-attribution` 1.1.0 also strips `Co-Authored-By: Claude` and `Claude-Session:` trailers from `git commit` and GitHub MCP commit messages.
