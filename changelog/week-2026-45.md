# Wins

- The router's weak half is activation, and a pre-turn hint fixes it. Over two pre-registered rounds, sessions with the router's routing table alone routed 45 of 54 positive runs correctly; with the hint added, 54 of 54. The hint named a route in 45 runs, was right every time, and stayed silent on every cell where the router should stay out.
- The router got a yes/no routing table (round 10) and `skill-authoring` got three notes on live docs, constraints vs guidance, and overfitting signals.

# What failed

- Nothing tested the cost of a wrong hint, because no hint was wrong. Adversarial prompts against the hint's first request are still owed.

# What changed in process

- A third-party API now runs in the session loop where the hint is installed. The owner accepted that trade; installs are project-local by default, the key stays in a file, and hook mode stores no user turns.
