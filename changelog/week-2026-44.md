# Wins

- `ai-stuff-artifact-router` got its first real evidence after 78 days as an evidence-free draft: 35 live OpenCode sessions across baseline / revision-1 / revision-2 conditions, with ground truth pre-registered and committed before the candidate was written.
- The router beats an unaided session on identical prompts in both full runs — 6/11 and 8/11 cases against a baseline of 3/11 — with zero regressions against the baseline in either run and zero false activations on the four stated non-activation conditions.
- Audited all 14 intent assignments in the router's manifest; four were wrong. Replaced intent-only indexing with Entry/Exit columns, which is what made the chain rule and the containment rule expressible at all.

# What failed

- **The round-1 headline did not reproduce.** 8/11 was measured against a superseded file hash; rerunning the same eleven cases against the shipped hash gave 6/11, with R1 and R5 flipping to failure. Variance in this artifact is now demonstrated rather than merely unmeasured, which closes the path to `vetted` ("repeatable") until activation is stabilised.
- **Activation, not routing, is the weak half.** Every routing failure across both runs was a case where the skill never engaged; every case it demonstrably engaged on was routed correctly. Two failures are activation losses to `skills/issues-to-roadmap`, whose description claims the same "break work down" verb.
- **An eval run committed a 141k-line deletion to this repo.** A baseline prompt dispatched with write permissions read "this internal template repo" as *this* repo and acted on it (`7a67eaf`, preserved as tag `eval-accident-7a67eaf`; tree restored to `ae9343d` and verified identical). Six runs discarded.

# What changed in process

- Every eval prompt now carries a read-only constraint, identical across conditions, and condition integrity (`git status`, symlink state) is verified after each batch. The constraint's cost is recorded: a session told not to act names procedures more readily than one told to act, which flatters the baseline.
- `experiments/` is now a hard non-routable boundary in the router, on owner instruction, and filesystem verification may only confirm or drop a manifest row — never add one. `experiments/arch-design-pipeline/` has a `playbook.md` and a `plan`-adjacent purpose, so the hole was reachable in one read. This also retires the manifest-generator idea with a concrete argument rather than a speculative one: a generator scanning for `playbook.md` would have routed live tasks into a draft experiment.
- `scripts/doc_lint.py` now excludes `experiments/*/evals/**`, matching the stated policy that already covered `skills/` and `prompts/`.
- Re-tested the router's embedded-manifest rationale instead of restating it: "drift is cheap to fix" turned out to be **unexercised**, not upheld. Zero playbooks added and zero status changes since 2026-08-04, so 14/14 manifest accuracy reflects an absence of drift events, not cheap repair. The vault's growth in that window was four skills — outside the manifest — and produced a scope collision instead of staleness.

# Index and standards corrections

- Root `README.md` lifecycle line omitted `skills/` as a promotion destination and implied `vetted` was a folder. Corrected, with the type-versus-trust distinction stated.
- `skills/README.md` listed `liteparse` as `draft`; the artifact itself is `validated`. Index was the wrong one.
- **Open, not fixed:** `_meta/framebook/classify-artifact/` requires of `skills/` that the artifact is "not a step-by-step procedure (that's a playbook)". Every skill in this vault is procedural, because a harness skill is a behaviour package rather than a reference document. The criterion misroutes all of them and needs a decision — `docs/standards/artifact-classification.md` wins on the conflict today, per the framebook's own precedence rule.
- **Open, not fixed:** DL011 forbids a promoted runtime artifact from containing the substring `experiments/`, to stop it depending on experimental files. It is a bare substring check, so it also blocks a runtime artifact from stating a *prohibition* on experiments — which is what the router's new boundary rule is. Worked around by rewording to "the `experiments` tree"; the rule itself cannot currently express the distinction.
- **Open, not fixed:** `experiments/design-skill/laws/sources/` holds full-text captures of nine copyrighted books, in git history, in the one directory `doc_lint.py` exempts from sanitization checks. A redistribution problem if this repo is ever published; deleting files will not fix history.
